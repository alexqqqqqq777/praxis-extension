# Praxis — практика Верховного Суду поруч із законом

Розширення для Chrome. Ви читаєте статтю на
[zakon.rada.gov.ua](https://zakon.rada.gov.ua) — праворуч зʼявляється панель із
правовими висновками ВС, привʼязаними не до статті цілком, а до конкретної
частини чи пункту. Біля кожної норми в тексті стоїть бейдж із кількістю рішень.
Окремий режим показує історію редакцій статті картками з підсвіченими змінами.

Дані — з Єдиного державного реєстру судових рішень.

---

## Чому цей репозиторій відкритий

Те, яку статтю закону читає юрист, — це натяк на справу, над якою він працює.
Тому продукт побудовано так, щоб про користувача не дізнавався ніхто, і щоб це
можна було **перевірити**, а не прийняти на віру.

Перевіряється клієнт. Відкрийте [`src/background.js`](src/background.js) — 38
рядків, єдине місце, звідки розширення виходить у мережу. Там видно все, що
залишає браузер: номер акта, номер статті, обрані фільтри й пошуковий рядок,
якщо ви ним скористалися. Ідентифікаторів немає.

Це і є доказ. Твердження про серверну частину доказом бути не можуть у принципі:
жодна публікація коду не підтверджує, що на сервері працює саме він. Тому тут
опубліковано не «все підряд», а рівно те, що робить перевірку можливою:

| що | де | навіщо |
|---|---|---|
| саме розширення, повністю | [`src/`](src), [`manifest.json`](manifest.json) | усе, що виконується у вас у браузері |
| транспортний шар сервера | [`server/praxis_http.py`](server/praxis_http.py) | 228 рядків: приймання запиту, ключ, CORS і **відсутність журналу** |
| конфігурація розгортання | [`deploy/`](deploy) | `access_log off`, `StandardError=null` — там, де журнал зазвичай і зʼявляється |
| політика приватності | [`PRIVACY.md`](PRIVACY.md) | без юридичної води |
| аудит | [`docs/PRIVACY-AUDIT.md`](docs/PRIVACY-AUDIT.md) | що знайшли, що виправили, що досі відкрито |

**Чого тут немає:** логіки добору й ранжування карток, зіставлення редакцій і
побудови корпусу. Це закрита частина проєкту. Вона не має стосунку до
приватності: ніхто не стає більш захищеним від того, що бачить, як саме ми
сортуємо постанови.

Важливіше інше — **закритий модуль не отримує даних про користувача взагалі**.
TLS термінує nginx, який вирізає IP (`X-Real-IP ""`, `X-Forwarded-For ""`);
транспортний шар передає далі лише розібрані аргументи: акт, статтю, фільтри.
Записати те, чого не бачив, не можна. Це властивість схеми, і вона перевіряється
по опублікованій частині.

## Контракт із модулем вибірки

`praxis_http.serve(core, host, port, token)` очікує від `core`:

```python
core.health()                                   -> dict
core.get_counts(act, refresh=False)             -> dict   # скільки рішень на кожну статтю
core.versions_count(act)                        -> dict   # у яких статей є редакції
core.norms_map(act, article)                    -> dict   # частини й пункти статті
core.get_cards(act, article, limit, part, **f)  -> dict   # картки рішень
core.article_history(act, article, part)        -> dict   # редакції з дифами
core.compare_dates(act, article, from_, to_, part) -> dict
core.version_text(act, article, on)             -> dict   # стаття станом на дату
core.act_info(nreg, in_act)                     -> dict   # картка акта-підстави
core.SORTS, core.JUSTICE, core.COURTS, core.FORM_NAMES    # словники для валідації
```

Жоден із цих викликів не приймає нічого про користувача — ані IP, ані
заголовків, ані ідентифікатора сесії. Підставте власний `core` — і транспорт
працюватиме без змін.

## Збірка

```bash
python3 tools/build-release.py --base https://ваша-вітрина
```

Складе `dist/` для Chrome Web Store: без демонстраційних даних, без дозволів на
локальну мережу, з `connect-src`, звуженим до однієї адреси.

Про демонстраційні дані окремо: у робочій теці розробника є набір із
**вигаданими** номерами справ, зручний, щоб малювати інтерфейс без бекенда. У
продукт він не потрапляє. Коли вітрина не відповідає, розширення каже «немає
звʼязку» і не показує нічого — вигаданої практики юристу показувати не можна.

## Встановлення з вихідників

1. `python3 tools/build-release.py`
2. `chrome://extensions` → увімкнути «Режим розробника» → «Завантажити
   розпаковане» → вибрати `dist/`
3. У попапі вказати адресу вітрини даних.
